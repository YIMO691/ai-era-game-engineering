## 如何处理后续证据

先在[来源登记](../research/sources.md)记录主张、报告位置、候选资料与缺失字段，再按[研究方法](research-method.md)判断证据能支持什么。

新找到相关资料，只能说明获得了新的支持或反证；除非能证明对应关系，不能称为“恢复了原报告引用”。第三方报告的数据也不能转写为本项目的测量结果。无法恢复的来源继续标记未核验，不猜测 URL、作者或数字口径。

发现错误时，在独立研究记录中给出更正、证据、影响范围和修改原因，保留原导入件及其身份。如果出现隐私或权利问题，应先停止相关材料的公开传播并处理，不以保真要求为由继续发布。
