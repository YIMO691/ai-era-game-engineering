# 专题精编版

每个研究专题的原文保留了完整的来源、审校与过程记录，信息完整但阅读负担较重。精编版把每个专题整理成“一句话—核心问题—观点体系—边界—编者注”的统一结构，作为首读入口。

## 精编版不是什么

- **不是新研究**：没有新增来源、实验或人工审核；证据状态继承原专题。
- **不替代原文**：原文、来源账本与导出清单保持不变，仍是追溯与引用的依据；精编版与原文冲突时以原文为准。
- **不是作者定稿**：每份精编版末尾的“编者注”列出整理时做的取舍，等待仓库所有者确认。

## 观点标签

精编版在每个观点标题后标注其性质，帮助区分哪些是论证、哪些是证据：

| 标签 | 含义 |
|---|---|
| 价值立场 | 选择追求什么；不需要也无法用实验证明 |
| 概念区分、工作定义、分析分类 | 为了讨论而作的区分；不是已验证的量表 |
| 源码 | 固定版本源码的静态阅读，未运行 |
| 研究 | 已读正文的外部研究，只在其研究设定内成立 |
| 逻辑、逻辑论证、逻辑反例 | 由定义或必要条件推出 |
| 推论、综合模型、实践建议、协议提案、决策提案 | 从材料归纳的工程判断，需要在项目中检验 |
| 迁移假设、验证设计、训练设计 | 尚未执行的设想 |
| 反命题 | 原专题主动保留的、可能推翻自身的观点 |
