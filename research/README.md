## 使用边界

- 先读专题README及审查记录，再使用正文和示例；不要把模板、评分框架或设计草案当行业标准。
- 来源登记分专题维护，不合并相似数字的统计口径，也不自动补齐原始报告引用。
- 实践模板中的配置与命令供审阅，不由本次发布自动安装或执行。
- [发布说明](PUBLICATION.md)记录范围、编辑源约定、排除项和验证边界；各专题导出清单记录输入与输出哈希。
- [来源总入口](sources.md)保留早期导入材料的缺口与后续专题入口。
